Sixm framework preview for Windows and Apple Silicon macOS.

- Windows: `Sixm.exe` browser-client launcher and `SixmServer.exe` standalone server; Python is bundled. Download the ZIP for both executables and instructions.
- macOS: drag `Sixm.app` from the DMG into Applications. Development signature only; not notarized.
- Server-owned maps, static assets, GLSL shaders, Python server resources and JavaScript client resources.
- Original-game integration is on hold pending an official PC version.

This is not the complete original game or a finished GTA VI port. No original game assets, executable, decompiled source or extractor are included. The existing Mac static-asset tooling remains a development experiment. Specialized materials, animation, original gameplay and full-map streaming remain incomplete.
