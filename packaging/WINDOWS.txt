SIXM WINDOWS PREVIEW

Sixm.exe opens a server's browser client. Double-click and enter the server HTTP URL,
or run: Sixm.exe http://127.0.0.1:6020

SixmServer.exe hosts the server and bundled authored test maps.
Custom map example:
  SixmServer.exe --maps C:\SixmMaps --map your-map --port 6020

For remote players, the operator can add --host 0.0.0.0.
Server console: maps | map <id> | feature <name> on/off | players | quit

The release executables include Python. Players do not need to install Python.
Rendering uses the default browser with WebGL 2. This is a Sixm framework preview,
not GTA VI, a finished GTA VI port, or a FiveM-compatible client.
No original game content or extractor is bundled. Original-game integration is
on hold pending an official PC version. See the GitHub repository for source
and the multiplayer resource API.
